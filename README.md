# BashMaster — Интерактивный самоучитель Bash

Полноценный интерактивный самоучитель Bash с 40 уроками и 148 практическими задачами. Обучение от основ до продвинутого уровня системного администрирования, DevOps и автоматизации.

## 📚 Содержание курса

### Базовый курс (уроки 1-10)
- Введение в Bash и навигация
- Работа с файлами и директориями
- Переменные и окружение
- Условные конструкции и циклы
- Потоки и перенаправления
- Поиск и фильтрация
- Текстовые процессоры (sed, awk)
- Написание скриптов

### Продвинутый курс (уроки 11-20)
- Права доступа и владельцы
- Управление процессами
- Сетевые команды
- Архивирование и сжатие
- Cron и автоматизация
- Системное администрирование
- Регулярные выражения
- Скрипты для администрирования
- Продвинутые скрипты
- Финальный проект

### Экспертный курс (уроки 21-30)
- Docker и контейнеризация
- Git из терминала
- Работа с базами данных
- Текстовые редакторы (Vim, Nano)
- Обработка JSON (jq)
- Отладка и диагностика
- Управление пользователями
- Сетевая безопасность
- Bash one-liners и трюки
- Финальный экзамен

### Ультимативный курс (уроки 31-40)
- Kubernetes (k8s)
- CI/CD: GitHub Actions
- Nmap и сетевая разведка
- OpenSSL и шифрование
- Tmux и Screen
- Обработка изображений (ImageMagick, FFmpeg)
- Работа с PDF
- Параллельное выполнение
- Bash Completion
- Мега-проект: Полная автоматизация

## 🚀 Инструкция по запуску

### Требования

- **Node.js** версии 18.0 или выше
- **npm** версии 9.0 или выше

Проверьте версии:
```bash
node --version
npm --version
```

Если Node.js не установлен, скачайте его с [официального сайта](https://nodejs.org/).

### Установка

1. **Клонируйте или скачайте проект**

2. **Перейдите в директорию проекта**
   ```bash
   cd bash-master
   ```

3. **Установите зависимости**
   ```bash
   npm install
   ```
   
   Эта команда установит все необходимые пакеты из `package.json`.

### Запуск в режиме разработки

Для запуска приложения в режиме разработки с горячей перезагрузкой:

```bash
npm run dev
```

После запуска вы увидите сообщение вроде:
```
  VITE v6.3.5  ready in 500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

Откройте браузер и перейдите по адресу **http://localhost:5173/**

### Сборка для продакшена

Для создания оптимизированной продакшен-сборки:

```bash
npm run build
```

Собранное приложение будет находиться в директории `dist/`.

### Предпросмотр продакшен-сборки

Для локального предпросмотра собранной версии:

```bash
npm run preview
```

### Проверка типов TypeScript

Для проверки типов без компиляции:

```bash
npm run typecheck
```

## 🔧 Решение проблем

### Ошибка: `npm: command not found`
Установите Node.js с [официального сайта](https://nodejs.org/)

### Ошибка: `Cannot find module`
Удалите `node_modules` и `package-lock.json`, затем выполните:
```bash
npm install
```

### Порт 5173 уже занят
Vite автоматически выберет другой порт, либо запустите:
```bash
npm run dev -- --port 3000
```

### Приложение не загружается
Очистите кэш браузера (Ctrl+Shift+R или Cmd+Shift+R)
